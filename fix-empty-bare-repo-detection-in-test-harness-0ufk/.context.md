literally), so create_clone always thought origin had commits and
never created .gitignore or an initial commit. This was masked by
a global gitignore on the developer workstation.

Fix: change rev-parse HEAD to cat-file -t HEAD which properly fails
on repos with no commits. Apply to both create_clone and
create_clone_with_file_url. Also clean up leftover debug code in
repo_has_yak step.
