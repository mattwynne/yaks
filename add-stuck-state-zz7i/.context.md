Add a "stuck" state to yaks: todo → wip → stuck → done.

"stuck" means "needs external input to proceed." Covers:
- Agent blocked, needs human help
- Work needs review before acceptance
- Waiting on external dependency

See GitHub issue #5 (mrdavidlaing feature request for
"waiting" state — same concept, we chose "stuck").

Status mapping for Disco integration:
  Disco "blocked" ↔ yaks "stuck"
  Disco "canceled" ↔ yaks removed (yx rm)

This is a prerequisite for the disco integration but
ships independently on main via TDD.
