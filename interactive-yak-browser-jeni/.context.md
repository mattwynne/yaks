# Goal
Full-screen interactive mode for browsing the yak tree — the "wow"
feature. Think `lazygit` but for yaks. Browse, expand/collapse,
change state, view context inline.

# Definition of Done
- `yx` (no subcommand) or `yx browse` opens interactive mode
- Tree view with expand/collapse
- Navigate with arrow keys / j/k
- Enter to view yak detail (context, fields)
- Keyboard shortcuts to change state (w=wip, d=done, t=todo)
- q to quit
