# Goal
Update `install.sh` so users get stable releases by default, but can deliberately choose a specific version or edge build.

# Desired behaviour
Default stable install:

```bash
curl -fsSL https://raw.githubusercontent.com/mattwynne/yaks/main/install.sh | bash
```

Specific version:

```bash
YX_VERSION=0.2.0 curl -fsSL https://raw.githubusercontent.com/mattwynne/yaks/main/install.sh | bash
```

Edge channel:

```bash
YX_CHANNEL=edge curl -fsSL https://raw.githubusercontent.com/mattwynne/yaks/main/install.sh | bash
```

# URL policy
- Default stable: use GitHub latest stable redirect, e.g. `/releases/latest/download/yx-${PLATFORM}.zip`.
- Specific version: `/releases/download/v${YX_VERSION}/yx-${PLATFORM}.zip`.
- Edge: `/releases/download/edge/yx-${PLATFORM}.zip`.

# Checksums
Current installer embeds checksums by release workflow. Preserve checksum verification if practical.

Potential approach:
- Stable/edge workflows upload an `install.sh` with embedded checksums for that release.
- Raw `main` installer can still work but may not have release-specific checksums unless it fetches checksum files.

# Definition of Done
- README installation docs explain stable/version/edge installation.
- Installer default no longer points at unstable `latest`.
- Tests cover URL selection for default, version, and edge.
