Add a `yx tag` command (alias: `yx tags`) for managing tags on yaks.

## Subcommands
- `yx tag add <yak> <tag>...` — add one or more tags
- `yx tag rm <yak> <tag>...` — remove one or more tags (alias: remove)
- `yx tag list <yak>` — list tags on a yak

## Storage
Tags stored in a first-class `tags` field on the yak, newline-separated.

## Tag naming rules
- No whitespace allowed
- Leading `@` is stripped on input (stored without prefix)
- Display with `@` prefix (e.g. `@v1.0`)

## Acceptance criteria
- `yx tag add "my yak" v1.0` stores "v1.0" in the tags field
- `yx tag add "my yak" @v1.0` also stores "v1.0" (@ stripped)
- `yx tag add "my yak" v1.0 needs-review` adds both tags
- `yx tag rm "my yak" v1.0` removes just that tag
- `yx tag list "my yak"` shows tags with @ prefix, one per line
- Adding a duplicate tag is a no-op
- Removing a non-existent tag is a no-op
- `yx tags` works as synonym for `yx tag`
- `yx tag remove` works as synonym for `yx tag rm`
