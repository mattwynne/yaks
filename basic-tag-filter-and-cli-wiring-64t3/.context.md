# Goal
Add --tag flag to `yx list` with TagFilter matching logic. Yaks that don't match are hidden (along with their subtrees — no ancestor context yet).

# Type
Feature

# Covers rules
- Single tag filter (exact match)
- OR within a clause (comma-separated)
- AND across clauses (multiple --tag flags)
- Combined AND/OR
- Combines with --only (AND)
- Tag normalization (strip @)
- No matches (empty output)

# Does NOT cover
- Ancestor context (parent shown when child matches) — that's the next yak

# Files
- Modify: `src/main.rs` — add `--tag` arg (repeatable Vec<String>) to List command, pass to ListYaks
- Modify: `src/application/list_yaks.rs` — add TagFilter struct, parsing, matching; filter nodes in display_tree
- Reuse: `src/domain/tag.rs` normalize_tag for stripping @
- Create: `features/filter_by_tag.feature` — scenarios for rules 1-4, 6-8 (skip ancestor context)

# Definition of Done
- `yx list --tag foo` shows only matching yaks
- `yx list --tag foo,bar` ORs within clause
- `yx list --tag foo --tag bar` ANDs across clauses
- `yx list --tag @foo` normalizes tag
- `yx list --tag foo --only done` combines filters
- All formats work (pretty, markdown, plain, json)
- All tests pass: `cargo test && cargo test --test cucumber`
