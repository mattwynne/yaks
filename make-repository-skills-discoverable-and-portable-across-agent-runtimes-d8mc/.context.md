# Goal
Resolve GitHub #21 by preserving the workflows for maintaining Yaks itself and making them usable by Claude contributors without Pi or Superpowers.

# Agreed decisions
- Generic yak mapping guidance belongs in CLI help, coordinated with GitHub #19: https://github.com/mattwynne/yaks/issues/19.
- Contributor skills live canonically in .agents/skills/.
- .claude/skills is a whole-directory symlink to ../.agents/skills.
- Two contributor workflows remain: prepare and work.
- Prepare preserves scope/design discussion, example mapping, BDD formulation, and agreed context stored on yaks.
- Work preserves claiming a yak, isolated worktrees, one-test-at-a-time TDD, dev check, dev merge, and completion.
- Delegation is optional and uses the current runtime's available capabilities.
- Both workflows explicitly identify their audience as contributors maintaining Yaks.
- Preserve supporting project skills such as BDD discovery/formulation, CQRS, mutation triage, sandboxing, exploratory testing, and ubiquitous language.
- Retire obsolete workflow experiments and the plugins/yx package once useful material is preserved.
- Do not add marketplace packaging, plugin installation, adapter skills, or duplicate workflow bodies.
- .pi/ deletion has not been authorized; leave it out of this cleanup.

# Completion
Children supply the implementation plan. Validate meaningful changes with focused tests and dev check; commit and merge through dev merge per AGENTS.md. Add contributor-facing release notes under Unreleased. Never edit .yaks directly or accepted ADRs.
