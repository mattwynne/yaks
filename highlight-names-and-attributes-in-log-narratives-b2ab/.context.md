# Goal
Yak names, author names, and other attributes in log narratives should be
highlighted with bold/colour, not plain text.

e.g. instead of:
  Matt Wynne added paginate log output like git log under yx log

it should render as:
  **Matt Wynne** added **paginate log output like git log** under **yx log**

(bold or coloured in the terminal)

# Approach
The narrative is currently built as a plain string by format_narrative().
To highlight specific parts, we need structured output — either:

Option A: Return a vec of spans (plain/highlighted) from format_narrative,
  and let the display layer render them with ANSI codes
Option B: Have the display layer do a post-hoc highlight pass, matching
  known names against the narrative string

Option A is cleaner. The EventFormat trait's format_narrative could return
a Vec<NarrativeSpan> where each span is either Plain(text) or Highlight(text).
The display layer then wraps Highlight spans in bold/colour ANSI.
