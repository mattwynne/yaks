# Goal

Make `yx list --ready` useful for agents by outputting a flat list of ready yak IDs instead of a pruned tree with broken connectors.

# Type

Feature / UX fix

# Problem

Current `yx list --ready` renders a partial tree. Because ancestors are omitted, connector/prefix rendering becomes confusing and visually broken. It also makes the output harder for agents to consume.

# Desired Behaviour

- `yx list --ready` defaults to a flat list of ready yak IDs, one per line.
- No tree connectors, no context, no ancestors.
- Ready means derived readiness is true: todo, unblocked, no incomplete children.
- This IDs-only output is the default for `--ready`; users should not need to add `--format ids`.
- Existing explicit formats can be handled separately, but the default ready output should prioritize agent consumption.

# Decision

`yx list --ready` should default to IDs only.

# Acceptance Notes

Current broken example includes orphaned connector prefixes such as `│  ╰─` without visible parents. The fix should remove that class of output entirely for default `--ready` output.
