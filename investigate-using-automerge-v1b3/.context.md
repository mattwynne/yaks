Learnings from research (2026-03-08):

## What Automerge is
- A CRDT library with a Rust core (`cargo add automerge`)
- JSON-like data structure: maps, lists, text, counters
- Multiple peers edit independently, merge automatically
- No conflicts, no coordination, no server required
- Transport-agnostic: provides a sync protocol, you bring
  your own transport (TCP, WebSocket, WebRTC, etc.)

## Why it fits yaks
- It's a library, not infrastructure — embeds in the yx
  binary. No daemon, no extra install step for users.
- The sync protocol is just binary messages exchanged
  between two peers — works over any connection.

## How it maps to the event-sourced architecture
Three options considered:
1. Replace events with Automerge — simpler sync but lose
   event history
2. Use Automerge just for sync — keep events locally,
   project into Automerge doc for replication
3. Event CRDTs (best fit) — model the event log as a
   grow-only set (G-Set) in Automerge. Events are immutable
   facts, so append-only replication is natural. Each peer
   appends events, syncs the set, projects locally.

Option 3 is most natural: events are immutable facts
("yak created", "state changed to wip") and a G-Set
replicates trivially.

## Peer discovery
Automerge has no built-in discovery. Options:
- Explicit peer addresses (simplest v1)
- mDNS for LAN (zero-config, easy to add)
- Rendezvous server (lightweight, stateless)
- DHT via libp2p (fully decentralized, complex)
- NAT traversal is the hard part for remote peers;
  Tailscale/ngrok sidestep it

## Architecture fit
Peer connectivity is a separate bounded context from
the yak map. In hexagonal terms, it's another port/adapter:
- YakMap aggregate — knows nothing about networking
- Peer adapter — handles sync transport
- Sync policy — glue: forwards events to peers, feeds
  incoming events into YakMap

## Comparison with Radicle
Radicle (P2P git collaboration) could also work since yaks
stores events in git refs, but it requires running a
radicle-node daemon — significant installation overhead
vs Automerge which is just a Rust dependency.
