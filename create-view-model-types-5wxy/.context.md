# Goal
Create domain value objects that carry all data needed for rendering,
decoupling use cases from display concerns.

# Definition of Done
- File created: src/domain/views.rs
- pub mod views added to src/domain/mod.rs
- YakDetailView struct: breadcrumb, name, state, metadata, context, children, fields, tags
- YakTreeView struct: Vec of tree nodes with name, state, tags, depth, connector hints
- LogEntryView struct: narrative spans, relative_time, event_id, commit_sha
- Message enum: Hint(String), Success(String), Info(String), Warn(String)
- All types derive Serialize (for JsonDisplay adapter)
- All types derive Debug, Clone
- cargo test passes (no tests needed yet — types only)
