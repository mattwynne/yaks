# Goal
New DisplayPort adapter that serializes view models to JSON on stdout.

# Definition of Done
- File created: src/adapters/json_display/mod.rs
- JsonDisplay implements DisplayPort
- show_yak serializes YakDetailView as JSON to stdout
- show_list serializes YakTreeView as JSON to stdout
- show_log serializes Vec<LogEntryView> as JSON to stdout
- message: Warn to stderr, others to stdout (as plain text, not JSON)
- width() returns 0 (unused for JSON)
- Unit tests verify JSON output structure

# Known Knowns
- View models derive Serialize — JsonDisplay just calls serde_json::to_string_pretty
- Replaces hand-built serde_json::json!() blocks in show_yak.rs and list_yaks.rs
- node_to_json_value helper in list_yaks.rs becomes unnecessary
- No need to match old JSON contract (confirmed: breaking changes OK)

# Known Unknowns
- Whether message() should output JSON or plain text for non-warn messages
