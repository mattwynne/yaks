# Goal
`yx log` should pipe through a pager (like `less`) when output is to a terminal,
just like `git log` does.

# Files
- Modify: src/main.rs or src/application/show_log.rs — set up pager before output
- Possibly: Cargo.toml — add a pager crate if needed

# Approach
- Use the `pager` crate or manually spawn `less -R` (the -R flag preserves ANSI colors)
- Only paginate when stdout is a TTY (not when piped)
- git uses GIT_PAGER / PAGER env vars — we could respect PAGER env var too
- Alternative: use the `minus` crate for built-in paging

# Definition of Done
- `yx log` paginates through less (or PAGER) when output is a terminal
- Piped output (`yx log | grep foo`) works without paging
- ANSI colors preserved in pager
- All tests pass: dev check
