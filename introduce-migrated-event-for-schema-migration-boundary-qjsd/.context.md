# Goal

Replace post-migration `Compacted` events with a new `Migrated` event type that:
- Stops `get_all_events()` from walking into old-schema history (same as Compacted does today)
- On replay, loads snapshot state from the git tree (same as Compacted)
- Does NOT trigger orphan reordering logic during merge
- Has no special handling in `merge_event_streams()`

This prevents the scenario where two repos independently migrate and produce divergent compaction snapshots that confuse the merge algorithm.

# Key code changes
- New `YakEvent::Migrated` variant
- `compact_ref()` in migration.rs emits Migrated instead of Compacted
- `get_all_events()` stops at Migrated commits (same as Compacted)
- `merge_event_streams()` ignores Migrated events (no orphan logic)
- Replay/projection handles Migrated same as Compacted (clear + rebuild)
