# Goal
Add an `--exclude-tag` option to `yx prune` so that done yaks with
a specific tag are preserved from pruning.

# Type
Feature

# Example
```bash
yx tag "important yak" keep
yx prune --exclude-tag keep
# "important yak" is still there despite being done
```

# Success Criteria
- `yx prune --exclude-tag <tag>` skips done leaves that carry `<tag>`
- `yx prune` (no flag) behaves exactly as before — removes all done yaks
- Single tag only (like --tag on list), not repeatable
- Ancestor preservation is implicit: if an excluded child is kept,
  its parent never becomes a leaf and is naturally preserved
- Children of an excluded parent CAN still be pruned (if they're
  done leaves without the tag)

# Design Decisions
- Implementation: add tag filter to the existing iterative
  leaf-pruning loop in yak_map.rs — just skip done leaves
  that carry the excluded tag
- Single --exclude-tag (not multiple), matching list's --tag pattern
- No new domain concept needed — just a predicate on the existing prune loop
