The agent should have ambient awareness of yak-shaving discipline: when working on any task, if it discovers prerequisite or tangential work, it should suggest capturing that as a yak rather than diving down the rabbit hole.

Examples:
- Mid-refactoring, notices a test helper could be improved → "Want to capture that as a yak? Lets stay focused on the current task."
- Implementing a feature, discovers a dependency needs upgrading first → "This looks like a blocker. Lets add it as a yak under the current one."
- Fixing a bug, spots an unrelated code smell → "I noticed X — want me to add a yak for it?"

This is the core yak-shaving insight: stay on task, capture tangents.

How this lands in the plugin is TBD — will be driven out by the evals yak. Could be part of the CLI reference/awareness skill, a dedicated behaviour, or plugin-level always-on context.
