Expose yaks domain operations to JS via wasm-bindgen.

Minimum API surface for Disco integration:
- Load events from serialized form → build YakMap
- Add yak (name, parent_id)
- Set state (todo, wip, done, stuck)
- Remove yak
- Rename yak
- Get projected tree (list of yaks with hierarchy)
- Serialize events for persistence

The WASM module does NOT do git I/O — that stays in JS
(isomorphic-git). The boundary is: JS handles persistence,
WASM handles domain logic.

Prerequisite: "add stuck state" and "status propagation"
must land first.

The native feature gate is already in place (branch
disco-integration-jzkg, commit a811e635).
