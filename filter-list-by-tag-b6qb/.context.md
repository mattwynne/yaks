# Goal
Add a `--tag` filter to `yx list` so users can narrow the list to yaks with specific tags.

# Type
Feature

# Success Criteria
- `yx list --tag foo` shows only yaks tagged `foo` (exact match)
- Multiple `--tag` flags are ANDed: `--tag a --tag b` means must have both
- Comma-separated values within a `--tag` are ORed: `--tag a,b` means has `a` or `b`
- Combined: `--tag blocked,need-design --tag epic` means (epic AND (blocked OR need-design))
- Ancestor yaks are shown for context even if they don't match (tree path to matching child)
- Combines with `--only` as AND (both filters must pass)
- Works across all output formats (pretty, markdown, plain, json)

# Design Decisions
- Exact match only, no patterns or prefixes
- `--tag` is repeatable (each occurrence adds an AND clause)
- Comma separates OR alternatives within one clause
- Ancestors shown to preserve tree structure, even if they don't match the tag filter
- Tag names use the same normalization as `yx tag add` (strip @ prefix)
