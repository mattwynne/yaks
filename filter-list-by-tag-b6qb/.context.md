# Goal
Add `--tag` filter to `yx list` to find yaks with a given tag. Flat output of matching yak IDs/names — no tree complexity.

# Type
Feature

# Success Criteria
- `yx list --tag foo` filters to yaks tagged `foo`
- Combines with `--only` as AND
- Works with existing formats (pretty, plain, json etc.)
- Tag names normalized (strip @ prefix)

# Design Decisions
- Single tag per --tag flag (keep it simple)
- Filter applied to flat yak list before tree building
- No ancestor context — just hide non-matching yaks and their subtrees
