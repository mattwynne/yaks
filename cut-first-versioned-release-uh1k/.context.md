# Goal
Use the new automation to publish the first stable versioned yaks release.

# Likely version
`v0.2.0`, because `Cargo.toml` currently says `0.1.0` and this is a meaningful release-process change.

# Steps
- Ensure all release automation yaks are done.
- Ensure changelog has useful `0.2.0` notes.
- Run the new release command, e.g. `dev release 0.2.0`.
- Push commit and tag.
- Verify GitHub Actions publishes stable release artifacts.
- Test the default installer installs the stable release.
- Test `YX_VERSION=0.2.0` installs that release.
- Test `YX_CHANNEL=edge` installs the edge release if edge workflow exists.

# Definition of Done
- GitHub has a non-prerelease `v0.2.0` release.
- Artifacts are attached.
- Release notes came from `CHANGELOG.md`.
- README install command works.
