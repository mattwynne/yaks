# Motivation
Mutation testing found a timeout mutant blocking the pre-commit hook.

**Mutant:** `src/application/reset_git_from_disk.rs:131:42: replace == with != in replay_yak`

The `replay_yak` function recursively replays yaks in parent→child order. Changing `==` to `!=` in the children filter causes it to select ALL yaks EXCEPT the actual children, leading to infinite recursion and a timeout.

# Current code

```rust
let children: Vec<&&Yak> = yak_index
    .values()
    .filter(|y| y.parent_id.as_ref() == Some(&yak.id))
    .collect();
```

# Goal
Kill this mutant so the pre-commit hook passes and the branch can be merged.

# Approach
Add a unit test that verifies `replay_yak` only replays actual children (not all other yaks). A test with a parent and two children where the children belong to different parents would catch this — the `!=` mutation would incorrectly select non-children, producing wrong replay events.
