# Goal
Add a `dev start <yak-name>` command that sets up a worktree for working on a yak.

# Steps
1. Look up yak ID via `yx show --format json` (needs "include id in yx show json output" yak first)
2. `yx start "<yak-name>"` (mark wip)
3. `git worktree add .worktrees/<id> -b <id>`
4. `yx field "<yak-name>" worktree ".worktrees/<id>"`
5. Print the worktree path
