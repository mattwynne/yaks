## Problem

Every use case has two identical `execute` methods:
- An inherent `pub fn execute(&self, app: &mut Application)` (the real implementation)
- A trait `impl UseCase for X { fn execute(...) { Self::execute(self, app) } }` (a one-liner that delegates)

Visible in `show_field.rs`, `remove_tag.rs`, `show_context.rs`, `write_context.rs`, `rename_yak.rs`, `edit_field.rs`, etc.

### Fix

Remove the inherent method and put the implementation directly in the trait impl. Or if the inherent method exists for testability/direct calling, document why.

### Impact

Low — code hygiene.
