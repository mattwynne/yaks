## Automatic sync (in progress)
Exploring real-time P2P sync using Automerge (CRDT library,
pure Rust). Two-layer approach: git for durable async sync,
Automerge over direct connections for real-time. NAT
traversal via ngrok/tunnels. Radicle was discounted (too
heavy — requires a daemon).

There's some ux polish we could do to the output when sync
runs, especially around being transparent when we resolve
merge conflicts.
