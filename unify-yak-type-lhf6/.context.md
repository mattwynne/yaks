# Goal
Replace YakView, YakEntry, and YakSnapshot with one Yak type.

# Definition of Done
- Single `Yak` struct in src/domain/yak.rs
- YakEntry removed from yak_map.rs
- YakSnapshot removed (or becomes From<&Yak> trivially)
- Aggregate (YakMap) holds HashMap<YakId, Yak>
- All tests pass

# Unified Yak Struct

pub struct Yak {
    pub id: YakId,
    pub name: Name,
    pub parent_id: Option<YakId>,
    pub state: YakState,
    pub context: Option<String>,
    pub fields: HashMap<String, String>,
    pub tags: Vec<String>,
    pub created_by: Author,
    pub created_at: Timestamp,
}

- children is excluded - it is derived/computed by scanning other yaks for matching parent_id. YakMap already does this via find_children_of(). Compute at the read/presentation layer when needed.
- id is redundantly stored inside the value (as well as the HashMap key) for convenience.
- YakSnapshot can either disappear entirely or become a trivial type alias / From<&Yak>.

# Approach
1. Start by making YakEntry carry all the fields YakView has
2. Rename it to Yak
3. Update YakMap to use Yak
4. Remove YakView
5. Update YakSnapshot to convert from Yak
6. Update all call sites
