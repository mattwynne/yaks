# Status

Mostly implemented; kept `wip` because the original child yak for `flake.nix` version bump is still unresolved.

Implemented:

- `bin/dev release VERSION` wraps `bin/release VERSION`.
- `bin/release` validates clean/up-to-date `main`, semver, tag uniqueness, changelog structure, and release-produced changes.
- It bumps `Cargo.toml`, refreshes `Cargo.lock`, promotes `CHANGELOG.md` `[Unreleased]` to `VERSION`, runs release checks, commits `Release vX.Y.Z`, creates an annotated tag, and pushes `main` + tag.

Differences from original plan:

- It takes an explicit version (`VERSION`) rather than `major|minor|patch`.
- It does not use `git-cliff`.
- It does not currently bump `flake.nix`.
