# Goal
Aggregate builds state by replaying events, not loading from
the read model projection.

# Definition of Done
- YakMap has apply(event) method that mutates internal Yaks
- YakMap::from_events(Vec<YakEvent>) replaces from_store()
- Command handler loads events from EventStore, replays them
- ReadYakStore no longer used by command handler (only by
  queries and display)
- All tests pass

# Known Knowns
- FieldUpdated carries field_name so apply() can dispatch
- Compacted events carry full snapshots — easy to hydrate
- Event stream is small (hundreds, not millions)

# Known Unknowns
- Does from_store() need to stay as a fallback or can it go?
- Performance: replay vs loading from projection. Probably
  fine given event count, but measure.
