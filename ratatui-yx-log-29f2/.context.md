# Goal
Replace the current `less -R` pager with an interactive ratatui
scrollable log view — the first truly interactive feature. Think
`tig` for yaks.

# Definition of Done
- `yx log` opens an interactive scrollable view (when TTY)
- Can scroll up/down through events
- Narrative spans rendered with highlighting
- Press q to quit
- Falls back to current pager-based output when piped

# Known Knowns
- Current impl pipes through `less -R`
- Events have NarrativeSpan (Plain/Highlight), timestamp,
  event_id, commit_sha
- This is the first INTERACTIVE feature — needs event loop
- ratatui List or Paragraph widget with scrolling
- Needs crossterm event handling for keypresses

# Known Unknowns
- Search/filter functionality — scope for v1 or later?
- How to handle very long logs (lazy loading vs load all)?
- Keybindings — vim-style (j/k) or arrow keys or both?
