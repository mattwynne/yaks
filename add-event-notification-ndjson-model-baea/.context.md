# Goal
Create the serializable NDJSON event notification model used by `yx events` commands.

# Files
- Create: `src/application/event_notifications.rs` (or similarly named application module)
- Modify: `src/application/mod.rs` to export the new helpers/types
- Modify: `src/adapters/views.rs` only if the event notification belongs with existing view DTOs instead
- Test: Rust unit tests in the new module

# Test Approach
- Unit-test conversion from `YakEvent` to an event notification JSON object.
- Cover at least `Added`, `FieldUpdated`, `Moved`, `Removed`, and `BlockerRemoved`.
- Assert the serialized object contains stable fields: `event_id`, `event_type`, `yak_id`, `yak_name`, `timestamp`, `author`, and `narrative`.
- Assert output is compact single-line JSON suitable for NDJSON, not pretty JSON.

# Definition of Done
- A public application-layer helper can turn a `YakEvent` plus name resolver into a compact JSON line.
- Unsupported/missing metadata is represented consistently, following existing `ShowLog` fallback patterns where sensible.
- No CLI command is added in this slice.
- Relevant unit tests pass; then run `dev check` before commit if practical.
