# mutation strategy doesn't work

We have a CI job that runs for every push and pull request, but the actual mutation testing only works on a PR, so it gets skipped when we push to main, which we do all the time.

We need a different strategy that allows us to know when we last ran mutation tests, so that pushes to main can get mutation tests too, but the build doesn't take forever. Perhaps we can use a git ref to mark a commit that's been tested for mutants?
