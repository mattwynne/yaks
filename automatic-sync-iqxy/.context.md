Goal: real-time sync between peers without manual `yx sync`.

## Approach
Two-layer design:
1. Git sync (baseline) — async, durable, works offline.
   Could auto-run after each command as a fire-and-forget.
2. Direct P2P sync (upgrade) — real-time when both peers
   are online, using Automerge over a direct connection.

## Key decisions
- Automerge is the preferred CRDT library (Rust, embeds
  in the binary, no daemon needed)
- Radicle was considered and discounted — too much
  installation overhead (requires a daemon)
- Peer connectivity is a separate bounded context from
  the yak map domain
- NAT traversal via ngrok/tunnels for remote peers
