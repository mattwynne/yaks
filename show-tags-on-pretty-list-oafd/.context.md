Display tags on yaks in both `yx show` and `yx list` output.

## yx show
Display tags with @ prefix after the yak name/state line, e.g.:
  @v1.0 @needs-review

## yx list
Display tags inline next to each yak in the tree view.

## Acceptance criteria
- `yx show "my yak"` displays tags when present
- `yx show "my yak"` shows no tag section when no tags
- `yx list` shows tags inline for yaks that have them
- Tags displayed with @ prefix
- `yx show --json "my yak"` includes tags in JSON output
