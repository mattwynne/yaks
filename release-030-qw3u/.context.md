# Goal

Publish v0.3.0, the next minor stable release after v0.2.0.

# Release notes

- Added `yx events watch` and `yx events wait-for-next` for scripts and agents to observe committed domain events.
- Changed readiness to be derived from workflow state, hierarchy, and blockers, with explanations in list/show/tree and JSON output.
- Changed `yx list --ready` to emit flat yak IDs by default.
- Changed external blocking from the `blocked` workflow state to manual blockers; legacy blocked yaks migrate to `todo` with a manual blocker.
- Fixed circular blocker/dependency errors to state that they are circular dependencies.

# Success criteria

- The above release notes are present in CHANGELOG.md under Unreleased, grouped by user impact.
- The release is prepared from clean, synchronized main using `bin/dev release 0.3.0`.
- GitHub Actions publishes the v0.3.0 stable release and its expected assets.
