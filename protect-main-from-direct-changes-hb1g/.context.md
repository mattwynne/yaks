# Goal
Prevent agents from doing implementation work directly in the main repo.

# Decision
Simple rule: if `.git` is a directory (main repo, not a worktree), only allow:
- `read` (non-destructive)
- `dev *` / `bin/dev *` commands
- `yx *` commands

Everything else (`write`, `edit`, any other `bash`) is blocked.

Detection: worktrees have `.git` as a file (pointing to main repo's `.git/worktrees/`), while the main repo has `.git` as a directory.

# Known edge case
- Piped commands like `echo "stuff" | yx context "foo"` start with `echo`, not `yx`, so they'd be blocked. Workaround: add `dev` subcommands for such patterns, or rework to avoid pipes.
