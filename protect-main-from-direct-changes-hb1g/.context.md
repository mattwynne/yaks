# Goal
Prevent agents from doing implementation work directly in the main repo.

# Decision
Simple rule: if `.git` is a directory (main repo, not a worktree), only allow:
- `read` (non-destructive)
- `dev *` / `bin/dev *` commands
- `yx *` commands

Everything else (`write`, `edit`, any other `bash`) is blocked.
Pipes into dev/yx are allowed (e.g. `echo "stuff" | yx context "foo"`).

   - `rules.ts` — pure decision logic
   - `index.ts` — wires rules to pi tool_call events
   - `rules.test.ts` — 29 tests
   - Detection: `.git` is a directory = main repo, `.git` is a file = worktree

2. **`yx show --format json` now includes `id` field**

3. **`dev start <yak-name>`** command

   - Marks yak as wip
   - Creates worktree at `.worktrees/<yak-id>`
   - Records worktree field on the yak
   - Idempotent (re-running is safe)
