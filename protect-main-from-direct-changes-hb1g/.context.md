# Goal
Expand the `.pi/extensions/protect-main.ts` extension to prevent agents from doing implementation work directly in the main repo.

# Current State
Extension exists and blocks `git commit` on main. Needs to also block:
- `git checkout <branch>` / `git switch` (switching main away from main)
- `write`/`edit` to source files (src/, features/, tests/) when cwd is the main repo

# Legitimate on main
- `git checkout -- <file>` (restoring files)
- `git checkout main` (getting back)
- Writing .pi/ config, bin/dev, skill files, .yaks/ via yx
- Running yx commands

# Key question
What's the precise rule for which file writes to block? Needs discussion.
