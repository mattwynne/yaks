## Goal
Define complexity thresholds and make `dev check` fail when they're exceeded, then iteratively tighten them.

## What needs to happen
1. Review the metrics output from `rust-code-analysis-cli` to understand current baseline
2. Set initial thresholds (e.g., max cognitive complexity per function) that the codebase currently passes
3. Wire threshold checking into `dev check` so it fails if any function exceeds the limit
4. Over time, tighten thresholds as code is refactored

## Depends on
- "wire rust-code-analysis into devenv and dev check" (must be done first)

## Acceptance criteria
- `dev check` fails if any Rust function exceeds the configured complexity threshold
- Thresholds are documented and easy to adjust
