# Goal
Make the `yx state` help/error text accurately show all valid states, including `blocked`.

# Problem
A user tried `waiting` as a state and the error said valid states were only `todo`, `wip`, `done`, even though `blocked` is supported.

# Definition of Done
- `yx state --help` examples/list include `blocked`.
- Invalid state errors mention all valid states: `todo`, `wip`, `blocked`, `done`.
- Tests cover the invalid state error/help text so it does not regress.
