# Goal
Generate GitHub Release notes automatically from `CHANGELOG.md` so release publishing does not require copy/paste.

# Desired behaviour
Given tag `v0.2.0`, extract the body under:

```markdown
## [0.2.0] - YYYY-MM-DD
```

until the next `## [` heading.

Use that extracted text as the GitHub Release body.

# Requirements
- Fail if the section is missing.
- Fail if the extracted notes are empty or only headings.
- Work locally too, so the release command can preview notes.

# Possible implementation
Add a small script, e.g.:

```bash
bin/changelog-section 0.2.0
```

Then GitHub Actions can do:

```bash
bin/changelog-section "$VERSION" > release-notes.md
```

and pass `body_path: release-notes.md` to `softprops/action-gh-release`.
