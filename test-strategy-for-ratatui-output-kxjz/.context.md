# Goal
Determine how to test display output when rendering via ratatui,
given our existing TestBuffer/ConsoleDisplay testing pattern.

# Definition of Done
- Clear approach documented for how InProcessWorld Cucumber tests
  will assert on ratatui-rendered output
- Spike code proving the approach works (render a widget, capture
  output, assert content)

# Known Knowns
- Current tests use TestBuffer (Vec<u8>) capturing raw writes
- InProcessWorld runs with color=false, width=60
- ratatui has TestBackend that captures a Buffer of styled cells
- ratatui Buffer has .content() to get cell text
- FullStackWorld tests capture yx binary stdout (unaffected)

# Known Unknowns
- Can we make ratatui render to our existing TestBuffer via
  crossterm writing to an arbitrary Write?
- Or do we need a parallel assertion path using TestBackend?
- Will test assertions need to change (cell-based vs string-based)?
