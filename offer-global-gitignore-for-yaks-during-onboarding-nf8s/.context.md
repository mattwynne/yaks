During the first-run onboarding flow, after offering to add .yaks to the project's .gitignore, also offer to add it to the user's global gitignore.

This means they never have to think about it again in any new repo.

Flow:
1. "Add .yaks to this project's .gitignore?" [Y/n] (existing)
2. "Would you also like to add .yaks to your global gitignore so it's ignored in all repos?" [Y/n] (new)

Detection: check `git config --global core.excludesFile` for the global gitignore path. If not set, suggest creating one (conventional location: ~/.config/git/ignore or ~/.gitignore_global).

If .yaks is already in the global gitignore, skip the prompt.
