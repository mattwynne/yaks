# Goal\nAfter a yak branch is successfully merged with `bin/dev merge`, mark the corresponding yak done automatically.\n\n# Expected behaviour\n- Successful `bin/dev merge <branch>` fast-forwards main, removes worktree/branch, and runs `yx done` for the yak whose id/branch matches `<branch>`.\n- If marking done fails, report a warning but do not roll back the already-completed merge.\n- Existing merge checks/rebase/cleanup behaviour is preserved.\n- Tests or a focused verification cover the helper logic if practical.\n\n# Motivation\nRelease yaks stayed WIP after their branches were merged because merge automation did not update yak state.
