# Goal

Explore replacing the `blocked` workflow state with explicit blocker relationships.

# Desired Model

A yak can have intrinsic workflow state plus unresolved blockers:

- workflow_state: `todo | wip | done`
- blocked_by: yak IDs / relationships

This should support a yak being blocked regardless of whether it is todo or wip.

# Related Yak

This overlaps with `sibling relationships/blocked_by`; decide whether to merge, move, or supersede that yak.
