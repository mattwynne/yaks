# Status

Closed as superseded / no longer required for the release flow that landed.

There is no `bin/dev changelog` command. Instead:

- `CHANGELOG.md` is maintained directly.
- `bin/changelog-section VERSION` extracts release notes for a version.
- `bin/check-release VERSION` validates that the changelog has non-empty notes.
- `bin/release VERSION` promotes `[Unreleased]` into the release section during release prep.

If we want a convenience command for editing/generating changelog entries later, create a new focused yak.
