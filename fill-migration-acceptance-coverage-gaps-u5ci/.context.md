- Replaying/resetting/migrating more than once does not duplicate manual blockers.
- Reset from disk/git compatibility paths preserve one manual blocker only.

## Compaction

- Compaction after migration stores the new model and does not persist `.state = blocked` again.

## Manual blocker guard coverage

- `yx start <yak>` fails clearly when the yak has an active manual blocker.
- `yx done <yak>` / setting state to `done` fails clearly when the yak has an active manual blocker.
- Removing the manual blocker makes the yak ready if otherwise unblocked.
