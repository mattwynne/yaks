# Goal
Add a CUCUMBER_WIP=1 env var mode that runs ONLY @wip-tagged scenarios,
so developers can iterate on work-in-progress acceptance tests.

# Files
- Modify: tests/cucumber.rs — add a CUCUMBER_WIP branch that filters to only @wip scenarios
  (mirror the existing CUCUMBER_MODE pattern)

# How it works
Currently tests/cucumber.rs checks CUCUMBER_MODE env var and filters OUT @wip scenarios.
Add a check for CUCUMBER_WIP=1 that inverts the filter — run ONLY scenarios tagged @wip.
Should work with both in-process and fullstack modes (respect CUCUMBER_MODE too).

# Usage
```
CUCUMBER_WIP=1 cargo test --test cucumber --features test-support
CUCUMBER_WIP=1 CUCUMBER_MODE=fullstack cargo test --test cucumber --features test-support
```

# Definition of Done
- CUCUMBER_WIP=1 runs only @wip scenarios
- CUCUMBER_WIP=1 combined with CUCUMBER_MODE=fullstack works
- Without CUCUMBER_WIP, behaviour unchanged (@wip excluded as before)
- All existing tests pass: `dev check`
