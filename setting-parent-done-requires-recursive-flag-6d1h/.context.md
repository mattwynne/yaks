# Bug

`yx state <parent> done` succeeds even when the parent has non-done children. It should refuse unless `--recursive` is passed, mirroring how `yx rm` behaves with children.

# Expected Behaviour

- `yx state <parent> done` → error mentioning `--recursive` when children are not all done
- `yx state <parent> done --recursive` → marks parent and all descendants as done
- `yx state <leaf> done` → works as before (no children, no flag needed)

# Discovered

Setting "configurable origin" to done succeeded despite its 3 children being in todo state.
