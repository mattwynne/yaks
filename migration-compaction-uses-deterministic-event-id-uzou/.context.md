# Bug

`compact_ref` in `migration.rs:194` uses a deterministic event-id
(`migration-to-v{version}`) for the Compacted event. When two repos
independently migrate to the same schema version, they produce
Compacted events with identical event-ids but different snapshots.

During merge, deduplication keeps only one copy (the local one),
discarding the other snapshot. This caused data loss when syncing
a stale repo that had independently migrated.

# Fix

Replace the deterministic event-id with a UUID:
```rust
format\!("Compacted\n\nEvent-Id: {}", uuid::Uuid::now_v7())
```
