# Goal
Add two tools to the show-yak extension so the agent can orchestrate the full yak workflow.

# Tools

## start_yak
- Accepts: yak name (space-separated words)
- Runs: `bin/dev start <name>`
- Returns: worktree path, branch name, yak context

## merge_yak
- Accepts: branch name
- Runs: `bin/dev merge <branch>`
- Returns: success/failure + output

# Orchestration (by the agent, not the tools)
1. `start_yak` → worktree path + branch + context
2. `show_yak` → read full yak details
3. subagent(worker, cwd=worktree, task=derived from context)
4. `merge_yak` → merge + cleanup
5. `yx done` → mark complete

# Implementation
- Add to .pi/extensions/show-yak/index.ts
- Use `pi.exec("bin/dev", ["start", ...nameWords])` and `pi.exec("bin/dev", ["merge", branch])`
- Parse worktree path from dev start output (last line: "✅ Worktree ready: <path> (branch: <branch>)")
- Timeout should be generous for merge (runs full check suite): 120s
