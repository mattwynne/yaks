# Goal
Add an optional excluded tag parameter to `YakMap::prune()` so done
leaves carrying that tag are skipped.

# Files
- Modify: src/domain/yak_map.rs — `prune()` method (line ~508)
- Test: features/prune.feature — new scenarios under a new Rule

# Approach
1. Write Gherkin scenarios in features/prune.feature for:
   - Done yak with excluded tag is kept
   - Done yak without excluded tag is pruned
   - Tagged done yak pruned when no flag given
   - Excluded parent with done untagged child (child pruned, parent kept)
   - Untagged done parent with excluded child (both kept)
2. Add step definition for pruning with exclude-tag
   (tests/features/steps.rs, test_world.rs, both worlds)
3. Change `prune()` signature to `prune(&mut self, exclude_tag: Option<&str>)`
4. Add tag check to the done_leaves filter: skip entries whose
   tags contain the excluded tag
5. Update existing callers to pass `None`

# Definition of Done
- New Gherkin scenarios pass in both in-process and full-stack worlds
- Existing prune scenarios still pass unchanged
- `dev check` passes
