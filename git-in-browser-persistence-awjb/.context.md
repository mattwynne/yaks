# Spike Findings: isomorphic-git Browser Persistence

## Verdict: Browser-only viable

A browser SPA can read, write, and push yaks events on
`refs/notes/yaks` using isomorphic-git. No server needed
beyond a stateless CORS proxy.

## What Works

1. **Clone** — isomorphic-git clones from GitHub via CORS
   proxy. Objects stored in IndexedDB via lightning-fs.
   Persists across browser sessions.

2. **Read notes ref** — `listServerRefs` finds the OID of
   `refs/notes/yaks` on the server. `fetch(remoteRef)` pulls
   the objects. `writeRef` stores the ref locally. Then
   `readCommit` → `readTree` → `readBlob` walks the full
   yak tree with complete fidelity.

3. **Write** — `writeBlob` → `writeTree` → `writeCommit` →
   `writeRef` creates new yaks in the correct tree shape.
   Verified by reading back.

4. **Push** — `git.push` with `onAuth` callback and a GitHub
   PAT pushes `refs/notes/yaks` through the CORS proxy.
   Verified by cloning the remote and confirming the new
   yak appeared.

5. **Auth** — Fine-grained GitHub PAT scoped to a single
   repo with Contents read/write is sufficient. GitHub OAuth
   App flow would provide tokens without user-managed PATs.

## Constraints & Workarounds

- **Notes refs not natively supported for fetch/store.**
  isomorphic-git doesn't auto-store non-standard refs. The
  workaround is a 3-step dance: `listServerRefs` → `fetch`
  with `remoteRef` → `writeRef`. Works fine.

- **CORS proxy required.** GitHub's git smart protocol
  doesn't send CORS headers. Need a stateless proxy
  (Cloudflare Worker / Vercel edge function, ~20 lines).

- **crypto.createHash polyfill.** isomorphic-git's CJS
  bundle uses Node crypto. Fixed with a tiny sha.js shim
  aliased via Vite config.

## Recommended Architecture

SPA (Disco + yaks WASM) → CORS proxy (stateless) → GitHub

- Host SPA on GitHub Pages
- GitHub OAuth App for auth (no PATs for users)
- CORS proxy as Cloudflare Worker (no state, no logic)
- IndexedDB for local persistence (offline-capable)
- Clone once, fetch deltas on revisit
