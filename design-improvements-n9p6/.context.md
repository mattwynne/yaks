## Design ideas for yx log

### Narrative-style event messages
- Author is part of the sentence, not a separate line
- Use yak names instead of IDs
- Plain English descriptions:
  - `Matt Wynne added "Fix the Bug"`
  - `Matt Wynne added "sync" under "things"`
  - `Matt Wynne started "sync"`
  - `Matt Wynne tagged "sync" with @foo, @bar`
  - `Matt Wynne moved "child" under "parent"`
  - `Matt Wynne renamed "old name" to "new name"`

### Three-line format per entry
1. **What happened** — narrative sentence (prominent)
2. **When** — relative timestamp in grey ("3 days ago", "just now")
3. **IDs** — event id and commit sha in grey

### Show commit SHA
- Label it explicitly: `sha: abc1234`
- Use abbreviated form (7 chars)

### Visual format
- Horizontal rule between entries
- Lines 2 and 3 in grey/dim

Example:

```
Matt Wynne added "Fix the Bug"
3 days ago
event: 019ca7a5  sha: abc1234
────────────────────────────────────────────────────────────────
Matt Wynne started "sync"
3 days ago
event: 88c37e62  sha: def5678
────────────────────────────────────────────────────────────────
Matt Wynne tagged "sync" with @foo, @bar
2 hours ago
event: 96fe76a2  sha: 789abcd
────────────────────────────────────────────────────────────────
```
