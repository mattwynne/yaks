## Design ideas for yx log

### Human-readable event messages
- Use yak names instead of IDs
- Describe changes in plain English:
  - `Added "Fix the Bug"` (not `Added: "fix-the-bug-x1y2" "Fix the Bug"`)
  - `Changed state of "sync" to "wip"` (not `FieldUpdated: "sync-q6qt" ".state"`)
  - `Tagged "sync" with @foo, @bar`
  - `Moved "child" under "parent"`
  - `Renamed "old name" to "new name"`

### Show commit SHA
- Label it explicitly: `sha: abc1234`
- Use abbreviated form (7 chars)

### New visual format
- Message is prominent at the top of each entry
- Metadata (event id, sha, author, date) in a grey footer line
- Horizontal rule between entries

Example:

```
Added "Fix the Bug"
  event: 019ca7a5  sha: abc1234  Matt Wynne · 2026-03-01 04:26
────────────────────────────────────────────────────────────────
Changed state of "sync" to "wip"
  event: 88c37e62  sha: def5678  Matt Wynne · 2026-03-01 04:28
────────────────────────────────────────────────────────────────
```
