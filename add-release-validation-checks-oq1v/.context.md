# Goal
Add checks that prevent bad releases from being published.

# Stable release checks
For tag `vX.Y.Z`:
- tag name parses as SemVer-ish `vMAJOR.MINOR.PATCH`
- `Cargo.toml` package version is `X.Y.Z`
- `Cargo.lock` is up to date
- `CHANGELOG.md` contains `## [X.Y.Z] - YYYY-MM-DD`
- release notes extracted from that changelog section are non-empty
- `yx --version` reports the expected version after build

# Where checks run
- In the stable release GitHub Actions workflow before publishing.
- In the local release command before creating commit/tag.

# Nice-to-have
Add a reusable script, e.g. `bin/check-release 0.2.0`, so the local command and CI use the same logic.
