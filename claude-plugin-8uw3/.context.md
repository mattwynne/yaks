
Or locally: `claude --plugin-dir ./plugins/yx`

# Design Decisions
- Plugin name: `yx` (skills invoked as `/yx:map` etc.)
- Three skills: map → prepare → work
- Map is lightweight structure discovery, not detailed planning
- Prepare fleshes out specs and acceptance criteria without
  prescribing specific techniques (no mandated example mapping etc.)
- Work owns yak lifecycle and worktrees, defers to project
  policies for implementation practices and verification
- @needs-human tag convention: tag when stuck, surface when
  encountered (conversation starter, not a wall)
- Subagent delegation: work dispatches one subagent per leaf
  yak in its own worktree; prepare delegates codebase exploration
- Skills are self-contained, no pi dependency
