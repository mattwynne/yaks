# Goal
`yx show --format json "yak name"` should include the yak's immutable ID in the output.

Currently the JSON has: name, state, breadcrumb, children, tags, context, etc.
Missing: `id` (e.g. `protect-main-from-direct-changes-hb1g`)

# Why
The `dev start` command needs the ID to create branch names and worktree paths.
The ID is stored in `.yaks/<path>/.id` but not exposed via the JSON API.

# Acceptance criteria
- `yx show --format json "yak name"` includes an `"id"` field
- The ID matches what's in `.yaks/<path>/.id`
