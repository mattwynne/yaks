# Goal
Simplify the domain model. A yak is a yak — one type, not seven.

# Motivation
The aggregate currently loads from the read model projection
(YakStore), building stripped-down YakEntry instances that throw
away data. Event sourcing the aggregate means it replays events
to build full Yak instances directly. This eliminates the need
for separate write-model and read-model representations of the
same concept.

# Definition of Done
- One `Yak` type replaces `YakView`, `YakEntry`, `YakSnapshot`
- Aggregate replays events to build state
- View types live in adapter layer, not domain
- All existing tests pass
- `dev check` passes
