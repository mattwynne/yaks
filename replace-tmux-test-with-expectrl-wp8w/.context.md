Replace the flaky tmux-based tab completion smoke test
(tests/shellspec/completion_smoke.sh) with a Rust integration
test using the expectrl crate.

The tmux test fails in sandboxed/CI environments because tmux
needs Unix sockets. expectrl uses PTYs directly — no daemon,
no sockets.

## What to do

1. Add expectrl as a dev-dependency
2. Create a new Rust integration test (e.g. tests/completion.rs)
   that spawns bash, sources completions/yx.bash, sends "yx \t",
   and asserts that command names (add, done, ls, etc.) appear
3. Delete tests/shellspec/completion_smoke.sh
4. Remove the tmux test from .shellspec if referenced
5. Verify the new test passes

## Acceptance criteria

- [ ] Rust integration test for tab completion passes
- [ ] tmux shellspec test removed
- [ ] dev check passes with no shellspec failures
- [ ] No Unix socket dependencies
