# Goal
Document the architectural patterns for using ratatui in the CLI.

# Content to Cover
- Two-adapter pattern: ConsoleDisplay (plain text, piped/CI) vs
  TuiDisplay (ratatui, TTY)
- Production rendering: CrosstermBackend + Viewport::Inline (no raw
  mode, no alternate screen)
- Testing: Buffer::empty + Widget::render + buffer_to_string() for
  unit tests; TestBackend for integration tests
- Why NOT to hand-roll ANSI from ratatui Buffers
- Routing: TTY + \!NO_COLOR → TuiDisplay, else → ConsoleDisplay

# Definition of Done
- ADR in docs/adr/ following existing format
- References spike findings and decisions made
