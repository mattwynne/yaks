Add a `yx prime` command that outputs a compact context summary
optimised for AI agent session priming.

Inspired by Beads' `bd prime` which generates ~1-2k tokens
auto-injected at session start. Key differences from Beads:

- No MCP server needed — just stdout that can be piped or
  captured by a SessionStart hook
- Focus on actionable state: what's wip, what's ready (leaf
  todo yaks with no incomplete children), what's blocked
- Include yak names, states, and parent context — skip fields
  and full context to save tokens
- Machine-readable (JSON) and human-readable modes

Example output sketch:
  ## Current Work
  - [wip] fix the build
  - [wip] launch > blog post

  ## Ready
  - launch > revise README
  - launch > yx prime

  ## Blocked (has incomplete children)
  - launch (4 of 6 children done)

This replaces the current pattern where agents must be taught
via CLAUDE.md to run `yx ls` and interpret the tree themselves.
