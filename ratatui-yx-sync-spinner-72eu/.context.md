# Goal
Show a spinner/progress indicator during `yx sync` when running
in a TTY. Quick win for perceived responsiveness.

# Definition of Done
- Spinner displays during sync operations (push/pull)
- Spinner replaced by success/failure message on completion
- No spinner when piped or NO_COLOR set
- Existing sync Cucumber tests unaffected

# Known Knowns
- Sync currently just prints "Syncing..." and then result
- ratatui has Gauge widget; ecosystem has spinner widgets
- Could also use a simpler approach (throbber-widgets-tui crate)
- Viewport::Inline(1) for a single-line spinner

# Known Unknowns
- Does sync take long enough for a spinner to matter?
- Async rendering while sync runs — threading implications?
