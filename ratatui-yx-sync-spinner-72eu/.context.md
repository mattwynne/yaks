# Goal
Show a spinner during `yx sync` for perceived responsiveness.

# Definition of Done
- Spinner displays during sync operations (fetch/push/rebuild)
- Spinner replaced by success/failure message on completion
- No spinner when piped or NO_COLOR set
- Existing sync Cucumber tests unaffected

# Known Knowns
- Sync is synchronous: event_store.sync() then rebuild
- Sync already receives &dyn DisplayPort — could use it
- Viewport::Inline(1) for a single-line spinner
- Sync takes ~1-2s typically (git fetch + push + replay)

# Known Unknowns
- Threading: spinner needs to animate while sync blocks.
  Probably spawn sync in a thread, animate spinner in main.
- Or: use a simple frame-based approach where sync calls
  back to update the spinner at each phase (fetch/push/rebuild)
