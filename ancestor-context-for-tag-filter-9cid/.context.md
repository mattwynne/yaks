# Goal
When filtering by tag, show ancestor yaks for tree context even if they don't match the filter. Children of matching yaks are NOT shown unless they also match.

# Type
Feature

# Depends on
- "basic tag filter and CLI wiring" (child yak) must be done first

# Covers rules
- Ancestor context: non-matching parent shown when child matches
- Child of matching parent hidden if child doesn't match
- Both shown when both match independently
- Full ancestor chain for deeply nested match
- Ancestor context with combined --only filter

# Design
Two-pass approach in display_tree:
1. First pass: compute set of yak IDs that match the tag filter (+ only filter)
2. Second pass: for each match, walk up parent chain to mark ancestors as "show for context"
3. Display: show matched yaks and context ancestors, skip everything else
Note: plain format should probably still only output matching yaks (no ancestors)
