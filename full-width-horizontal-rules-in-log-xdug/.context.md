# Goal
The horizontal rule separators in `yx log` should span the full terminal width,
not a fixed 40 characters.

# Files
- Modify: src/adapters/user_display/mod.rs — detect terminal width and use it for the rule

# Approach
- Use the `terminal_size` crate (or similar) to get terminal width
- Fall back to 80 if width can't be detected (e.g. piped output)
- Replace the hardcoded "────────────────────────────────────────" with a
  dynamically generated string of ─ characters matching terminal width
- The rule should still be dim when color is enabled

# Definition of Done
- Horizontal rules span full terminal width
- Falls back gracefully when width unknown
- All tests pass: dev check
