Integrate with jonfazzaro/disco (disco.fazzaro.com) to provide a
visual web UI for yaks. Disco is a React app for Discovery Trees
— hierarchical work items with status propagation.

Approach: compile yaks' Rust domain + application layers to WASM,
run in the browser, and write browser-native port adapters. Replace
Disco's Firebase Forest adapter with one backed by yaks/git.

Key challenges:
- Git in the browser (isomorphic-git or wasm-git)
- Auth and pushing to remotes from browser
- Mapping Disco's status model (new/doing/done/blocked/canceled)
  to yaks (todo/wip/done)
- Real-time sync when multiple users have it open

Disco repo: https://github.com/jonfazzaro/disco
Disco architecture: hexagonal, React 19, Forest port with pluggable
adapters (Firebase RTDB, LocalStorage).
