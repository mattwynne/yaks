# Disco Integration — Option B (decided)

Yaks' domain model runs in the browser via WASM. Disco is
the UI shell. CLI and browser share the same git data with
CRDT merge for concurrent editing.

## Decisions Made (2026-04-13)

- CLI ↔ browser interop: yes, required for v1
- Concurrent multi-user editing: yes, via CRDT event merge
- Status mapping: add "stuck" to yaks (= Disco "blocked"),
  removed = Disco "canceled"
- Real-time sync: pull-based ok for now
- Architecture: Option B — full WASM domain

## Status Mapping

  Disco       Yaks
  new     →   todo
  doing   →   wip
  done    →   done
  blocked →   stuck (new state)
  canceled →  removed (yx rm)
