Implement Disco Forest interface backed by yaks WASM
domain + isomorphic-git for git I/O.

Forest interface (from Disco):
  load(callback?) → Promise<Leaf>
  save(tree: Leaf) → Promise<void>

Implementation:
- load(): clone/fetch repo via isomorphic-git, read
  events from refs/notes/yaks, feed into WASM domain,
  project to Leaf tree for Disco UI
- save(): diff Disco Leaf tree against WASM domain state,
  emit yaks events, write to git, push

Status mapping at this boundary:
  Disco blocked ↔ yaks stuck
  Disco canceled ↔ yaks removed
  Disco new ↔ yaks todo
  Disco doing ↔ yaks wip
  Disco done ↔ yaks done

Prerequisite: wasm-bindgen JS bindings.
