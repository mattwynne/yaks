Implement Disco Forest interface backed by Yaks WASM domain + isomorphic-git for git I/O.

Forest interface (from Disco):

```typescript
load(callback?) → Promise<Leaf>
save(tree: Leaf) → Promise<void>
```

Implementation sketch:

- `load()`: clone/fetch repo via isomorphic-git, read events from refs/notes/yaks, feed into WASM domain, project to Leaf tree for Disco UI.
- `save()`: diff Disco Leaf tree against WASM domain state, emit Yaks events, write to git, push.

# Status Mapping Warning

The old mapping `Disco blocked ↔ Yaks stuck` is stale. Yaks no longer models blocked/stuck as workflow state.

Current likely mapping:

```text
Disco new      ↔ Yaks todo
Disco doing    ↔ Yaks wip
Disco done     ↔ Yaks done
Disco blocked  ↔ TBD: manual blocker / derived readiness / boundary-only presentation
Disco canceled ↔ Yaks removed
```

Before implementing this adapter, revisit and document the status mapping under the new Yaks workflow-state/readiness model.

Prerequisite: wasm-bindgen JS bindings plus a fresh Disco status-mapping decision.
