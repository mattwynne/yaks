# Goal

Add --show flag to yx sync that displays the current sync
target without actually syncing.

# Depends On

"sync reads git config" must be done first.

# Files

- Modify: src/main.rs — the Sync struct (from the "yx sync
  url sets target" yak) already has show: bool. If that yak
  isn't done yet, add it here.
- Create or modify: src/application/ — handler for show mode
- Modify: features/sync.feature — scenarios for --show
- Modify: tests/features/steps.rs — step defs for
  "runs yx sync --show"

# Behaviour

- If yaks.remote is set: print the configured URL
- If yaks.remote is unset but origin remote exists: print
  origin's URL with "(origin)" suffix
- If neither: print "Not connected"

# Test Approach

TDD with Cucumber:
1. Scenario: shows configured URL when yaks.remote set
2. Scenario: shows origin URL with "(origin)" when not set
3. Scenario: shows "Not connected" when no remote at all

# Definition of Done

- yx sync --show prints correct target in all three cases
- Does not actually sync
- dev check passes
