Write ADR 0023 (or next number) superseding ADR 0012
"Compact after migration to hide pre-migration history".

New decision: Lazy migration replaces boundary events.
- Migration upgrades the tip tree only, no boundary commit
- get_all_events() lazily migrates old-format trees at read time
- Migrated events are stripped during merge for backward compat
- Compaction remains a separate user-triggered operation
- Motivation: Migrated boundary events caused data loss when
  stale machines synced (the bug that prompted this change)
