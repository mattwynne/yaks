# Spec: Refactor plugin hint into use case

## Goal
Extract the plugin hint banner from main.rs free functions into
proper hexagonal architecture: use case, ports, and adapters.

## Why
Code review found the current implementation violates three ADRs:
- ADR 0017: hand-rolled ANSI from ratatui Buffer
- ADR 0008/0013: policy logic and subprocess calls in main.rs

## What to do
1. Create PluginDetectionPort trait in domain/ports/
2. Create ClaudePluginDetection adapter (shells out to claude)
3. Create InMemoryPluginDetection for tests
4. Create MaybeShowPluginHint use case in application/
5. Move render_bordered_box/buffer_to_ansi into an adapter
6. Wire in main.rs, remove free functions
7. Move NullWorkspace out of main.rs into adapters

## Acceptance Criteria
- [ ] No policy logic or subprocess calls in main.rs
- [ ] Plugin detection behind a port trait
- [ ] Rendering code in an adapter, not main.rs
- [ ] All existing Cucumber tests still pass
- [ ] dev check passes
