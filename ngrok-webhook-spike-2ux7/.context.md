Spike: use ngrok (or similar tunnel service) + webhook to enable
real-time P2P sync between yaks peers.

Concept:
- `yx sync serve` starts a local sync listener + opens a tunnel,
  prints a public URL
- The URL is shared via git-synced state (e.g. a dedicated ref
  like refs/yaks/peers/alice), NOT as a domain event — peer
  connectivity is a separate bounded context from the yak map
- Remote peer picks up the URL via normal git sync, then
  connects directly for real-time Automerge sync
- Graceful degradation: git sync is the baseline (async),
  direct connection upgrades to real-time when both online

Open questions:
- Ephemeral URLs: ngrok URLs change each session. Need TTL or
  heartbeat. Maybe a "peers" file rather than events.
- Stale URLs: peer goes offline, URL dies. Need timeout logic.
- NAT traversal alternatives: Cloudflare Tunnels, bore, localtunnel
- Could Tailscale/WireGuard be simpler for dev teams?
