# Goal
Make the no-think release command publish the release too.

# Problem
`bin/dev release VERSION` prepares a release commit and tag, then prints a manual `git push` command. In the guarded main checkout, raw `git push` is blocked, which forced a subagent/worktree workaround. That is a hack.

# Expected behaviour
- `bin/dev release VERSION` still performs the existing safety checks, version bump, changelog promotion, validation, commit, and annotated tag creation.
- After creating the tag, it automatically pushes `main` and the release tag to the configured remote without asking for confirmation.
- The command should remain safe: only push after all checks and release prep succeed.
- The success message should say the release was pushed and GitHub Actions will publish artifacts.
- Tests/docs are updated as appropriate.

# Notes
User explicitly said no confirmation is needed.
