# Goal

Add optional positional URL argument to yx sync. When
provided, verify the URL is reachable (git ls-remote) and
store it in git config yaks.remote. Print confirmation.

# Depends On

"sync reads git config" must be done first.

# Files

- Modify: src/main.rs — change Sync from unit variant to
  struct with optional url: Option<String> and show: bool
  fields (lines ~239-241, ~527)
- Create or modify: src/application/connect_sync.rs — new
  use case for the connect flow (verify + store)
- Modify: features/sync.feature — scenarios for setting
  valid and invalid URLs
- Modify: tests/features/steps.rs — step defs for
  "runs yx sync with the URL of <name>"
- Modify: tests/features/full_stack_world.rs — if needed

# Test Approach

TDD with Cucumber:
1. Scenario: setting a valid URL stores it and prints
   confirmation — RED, implement, GREEN
2. Scenario: setting an unreachable URL fails and stores
   nothing — RED, implement, GREEN

# Definition of Done

- yx sync <url> verifies via git ls-remote before storing
- Stores in git config yaks.remote
- Prints "Connected to <url>" on success
- Fails with error on unreachable URL
- yx sync (no args) still syncs normally
- dev check passes
