# Ratatui UI Delight

## Compromises to Undo
These were made during the PoC and should be addressed as we convert
more methods to ratatui:

1. **ConsoleDisplay fallback** — TuiDisplay delegates unconverted
   methods to ConsoleDisplay. As each method gets its own ratatui
   rendering, remove the delegation and eventually the fallback field.

2. **Missed mutants in render_header_box** — 8 mutants survive in
   styling logic (state_color match arms, child styling). Need tests
   that assert on cell-level Color values, not just text content.

3. **display_header_box production path** — The CrosstermBackend +
   Viewport::Inline creation is not unit-tested (needs real TTY).
   Consider ratatui-testlib with PTY for Cucumber integration tests.

## Architecture (confirmed by PoC)
- ConsoleDisplay: plain text, Write-based, piped/CI/NO_COLOR
- TuiDisplay: ratatui widgets, CrosstermBackend + Viewport::Inline
- Route at startup: TTY + \!NO_COLOR → TuiDisplay
- Tests: TestBackend + Viewport::Fixed via draw_header_box<B>
- Unconverted methods delegate to ConsoleDisplay fallback
