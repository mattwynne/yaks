# Ratatui UI Delight

## Goal
Add visual delight to the CLI using [ratatui](https://ratatui.rs/) —
the mature Rust TUI framework (v0.30, 18.7k stars, used by Netflix,
OpenAI, AWS).

## Why ratatui over bubbletea-rs?
bubbletea-rs is too immature (v0.0.9, 250 stars, 69 commits).
Ratatui is battle-tested with a massive ecosystem (2,500+ community
crates).

## Architecture fit
The existing `DisplayPort` trait is the perfect seam:
- Keep `ConsoleDisplay` for non-interactive output (piped, CI, JSON)
- Add a `RatatuiDisplay` adapter for rich terminal output
- Route based on TTY detection (already in place)
- No changes needed to domain or application code

## Candidate areas (ordered by effort/impact)
1. **yx show** — box/detail view (medium effort, high delight)
2. **yx log** — scrollable interactive event log (medium, high)
3. **yx sync** — progress spinner (low effort, quick win)
4. **yx ls** — tree rendering (low effort, modest win)
5. **Interactive yx** — full-screen browse/edit mode (ambitious)
