# Ratatui UI Delight

## Status
PoC complete and merged to main. Next: refactor DisplayPort interface
before converting more methods.

## Architecture (confirmed by PoC, documented in ADR 17)
- ConsoleDisplay: plain text, Write-based, piped/CI/NO_COLOR
- TuiDisplay: ratatui widgets, CrosstermBackend + Viewport::Inline
- Route at startup: TTY + \!NO_COLOR → TuiDisplay
- Tests: TestBackend + Viewport::Fixed via draw_header_box<B>
- Unconverted methods delegate to ConsoleDisplay fallback

## Key Files
- src/adapters/tui_display/mod.rs — TuiDisplay implementation
- src/adapters/user_display/mod.rs — ConsoleDisplay (unchanged)
- src/domain/ports/user_display.rs — DisplayPort trait (to refactor)
- src/main.rs — TTY routing logic
- docs/adr/0017-ratatui-tui-display-adapter.md — ADR
