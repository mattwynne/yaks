The `protect-main` pi extension blocks bash commands in the main repo to prevent accidental changes. However, the agent currently has no way to discover file paths — `read` works on files but not directories, and bash is blocked.

Add two new tools to the protect-main extension:

## `find`

Find files by name/path pattern. Like `find` or `ls`.

**Parameters:**
- `path` (required) — directory to search in
- `pattern` (optional) — glob or regex to filter file names
- `recursive` (optional, boolean) — whether to recurse into subdirectories (default: true)

## `search`

Search for content within files. Like `rg` or `grep -r`.

**Parameters:**
- `pattern` (required) — string or regex to match within file contents
- `path` (optional) — directory to scope the search to (default: project root)
- `glob` (optional) — file type filter, e.g. `*.feature`

Both tools are read-only and safe to use in the main repo.
