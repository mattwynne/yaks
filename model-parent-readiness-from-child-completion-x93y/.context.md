# Goal

Make parent yak readiness reflect child completion.

# Desired Behaviour

- A parent with incomplete children should not look like direct active work just because a child is being worked on.
- The parent should be unavailable/blocked while children remain incomplete.
- When the final incomplete child becomes done, the parent should become ready/actionable again.
- Prefer a domain rule that avoids surprising implicit mutation if possible.

# Design Question

Should this be represented by mutating parent state, or by deriving readiness from the child tree at read time?
