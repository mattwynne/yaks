# Goal
Re-render `yx show` output using ratatui widgets for a more polished
detail view — the highest-impact visual upgrade.

# Definition of Done
- `yx show` renders header box using ratatui Block/Table widgets
- Breadcrumb, metadata, children list styled with ratatui
- Context section (markdown) still rendered (termimad or ratatui)
- Graceful fallback for piped output (plain text, no ratatui)
- Existing Cucumber scenarios for `yx show` still pass

# Known Knowns
- Current implementation: display_header_box() in ConsoleDisplay
  draws Unicode boxes with hand-rolled ANSI
- Uses Viewport::Inline since this is write-and-exit, not interactive
- ratatui has Block, Paragraph, Table, List widgets
- Can render using ratatui only when TTY detected
