# Goal
Re-render `yx show` using ratatui widgets for a more polished
detail view — the highest-impact visual upgrade.

# Definition of Done
- `yx show` header box rendered via ratatui Block/Table widgets
- Breadcrumb, metadata, children list styled with ratatui
- Context section still renders (termimad or ratatui markdown)
- Graceful fallback for piped output (plain text, no ratatui)
- Existing Cucumber scenarios for `yx show` still pass

# Known Knowns
- Current impl: display_header_box() in ConsoleDisplay (~100 lines)
  draws Unicode boxes with hand-rolled ANSI
- Uses Viewport::Inline since write-and-exit, not interactive
- ratatui has Block, Paragraph, Table, List widgets
- Render only when TTY detected (already in place)

# Known Unknowns
- How to integrate termimad markdown inside ratatui frame?
  (or replace termimad with ratatui-native markdown?)
- Exact visual design — needs experimentation
- Whether to render entire show output as one ratatui frame
  or mix ratatui (header box) with existing code (context body)
