## Goal
Add `rust-code-analysis` to the development environment and integrate it into `dev check` as a code quality gate.

## Background
`rust-code-analysis` is a Rust library/CLI tool that analyzes source code and extracts metrics (cognitive complexity, cyclomatic complexity, LOC, etc.) using Tree Sitter parsers. It's available in nixpkgs as `rust-code-analysis` (v0.0.25).

## What needs to happen
1. Add `rust-code-analysis` to `devenv.nix` packages list
2. Add a metrics check step to the `check()` function in `bin/dev` that runs `rust-code-analysis-cli --metrics` on Rust source files and fails if complexity thresholds are exceeded

## Key files
- `devenv.nix` — nix development environment config
- `bin/dev` — argc-based dev CLI with `check()` function (quality gate)
