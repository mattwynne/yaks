# Goal

Allow syncing yaks with a remote URL that isn't the current
repo's "origin" — e.g. a team meta-repo for shared yaks
across multiple code repos.

# Type

Feature

# Success Criteria

- `yx sync` works unchanged for existing users (defaults to
  origin remote when nothing configured)
- `yx connect <url>` verifies reachability via git ls-remote,
  then stores the URL in git config (yaks.remote)
- `yx connect` (no args) shows the current sync target
- `yx sync` uses the configured URL for fetch/push when set
- Syncing across unrelated repos works (meta-repo use case)
- "Sync not configured" error when neither yaks.remote is
  set nor an origin remote exists

# Design Decisions

- Store URL in git config (yaks.remote), not a file or env var
- Pass URL directly to git fetch/push — no named remote
  needed, avoids mixing remotes from unrelated repos
- Verify URL reachability on connect (git ls-remote)
- No disconnect command (YAGNI)
